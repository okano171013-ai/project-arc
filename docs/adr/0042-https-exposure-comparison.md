# ADR 0042: HTTPS公開方式の選定理由

## ステータス

承認済み（比較・推奨のみ。実際の導入はOwner判断待ち）

## 関連Principle

- Principle 9（段階的拡張／YAGNI）
- 安全ガイドライン（アカウント作成・外部サービスへの契約はClaude Codeが代行できない）

## コンテキスト

ChatGPT Developer ModeからRemote MCPサーバーへ接続するには、公開
HTTPSでの到達性が必須（事前調査、ADR 0041）。Project ARCは
`127.0.0.1`ローカル専用で運用されてきた（ADR 0008）ため、何らかの
トンネル手段で一時的または恒久的に公開する必要がある。指示書5章の
指示に従い、候補を比較する。ただし、いずれの選択肢もアカウント
作成を伴うため、**実際の導入・契約はClaude Codeでは行わず、
Owner自身の操作が必要**（安全ガイドライン上の制約：アカウント作成・
外部サービスへの契約行為は代行できない）。

## 比較（事前調査に基づく）

| | Cloudflare Tunnel | Tailscale Funnel | ngrok |
|---|---|---|---|
| 無料枠 | あり、帯域無制限 | あり（最大6ユーザー） | あり（2026年時点で1GB・2時間セッション制限、無料枠は縮小傾向） |
| アカウント要否 | 要 | 要 | 要 |
| 独自ドメイン | 可（Cloudflareで管理するドメインが必要） | 不可（`*.ts.net`のみ、正式な証明書は自ドメインに使えない） | 有料プランのみ（$8/月〜） |
| セットアップ複雑度 | 中（`cloudflared`導入＋DNS設定） | 低（既にTailscaleを使っていれば） | 低（単一バイナリ） |
| セキュリティ特性 | Cloudflareのエッジを経由 | WireGuardメッシュ、HTTPSは443/8443/10000限定 | 無料枠は訪問者向け警告インタースティシャルあり |

## 決定

**初回の動作検証にはngrok、恒久的に運用する場合はCloudflare Tunnel
を推奨する**（Owner判断待ち、いずれも本Versionでは導入しない）。

- **ngrok**：セットアップが最も簡単で、「Remote MCP → ChatGPT」接続が
  実際に機能するかを一度確認するだけの目的（指示書15章の実機確認）
  には十分。ただしセッション時間制限があるため、恒久運用には
  不向き。
- **Cloudflare Tunnel**：Ownerが既にCloudflareで管理しているドメインが
  あれば、帯域無制限・無料で恒久的な公開URLを維持できる。設定は
  ngrokよりやや複雑。

Tailscale Funnelは、Owner・ARC間の接続がTailscaleネットワーク越しに
限定されるため、ChatGPT（外部の第三者サービス）からの接続という
今回のユースケースには不向きと判断し、優先度を下げた。

## 根拠

- いずれも無料枠の範囲で検証可能であり、有料契約を急いで結ぶ必要は
  ない（指示書「有料サービス導入前には必ずOwnerへ相談すること」）。
- Claude Codeはアカウント作成・外部サービスへの契約を代行できない
  （安全ガイドライン）。トンネルの実際の設定・運用はOwner自身が
  行う必要があり、Claude Codeの役割は比較検討の提示と、選ばれた
  方式に応じた起動手順のドキュメント化（`docs/setup/
  chatgpt-mcp-connection.md`）に留まる。

## 影響

- Project ARC本体・Remote MCPサーバーのコードは、どのトンネル手段を
  選んでも変更不要（Remote MCPサーバーは`127.0.0.1`でリッスンする
  だけであり、公開方法に依存しない設計にしてある）。
- Ownerがトンネル方式を選定・契約した後、`docs/setup/
  chatgpt-mcp-connection.md`の該当セクションに従って起動すれば
  接続できる。
