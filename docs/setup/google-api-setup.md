# Google API セットアップ手順書

Project ARC Version3で、Google Calendar / Google Tasksと連携するために
必要な準備です。この作業はブラウザでの手動操作が必要なため、
Owner自身に行っていただく必要があります。所要時間は10〜15分程度です。

一度セットアップすれば、Project ARC側の認証は初回の1回だけで済みます
（詳細は「3. 初回認証について」を参照）。

---

## 1. Google Cloud Consoleでプロジェクトを作成

1. [Google Cloud Console](https://console.cloud.google.com/) にアクセスし、
   普段使っているGoogleアカウントでログインする
2. 上部の「プロジェクトの選択」→「新しいプロジェクト」
3. プロジェクト名は何でも良い（例：`project-arc`）
4. 「作成」をクリック

## 2. APIを有効化する

作成したプロジェクトを選択した状態で:

1. 左メニュー「APIとサービス」→「ライブラリ」
2. 検索窓で「**Google Calendar API**」を検索 → 選択 →「有効にする」
3. 同様に「**Google Tasks API**」を検索 → 選択 →「有効にする」

## 3. OAuth同意画面を設定する

1. 左メニュー「APIとサービス」→「OAuth同意画面」
2. User Type は「**外部**」を選択（個人のGoogleアカウントを使うため）
3. アプリ名（例：`Project ARC`）、ユーザーサポートメール、
   デベロッパーの連絡先情報を入力して保存
4. 「スコープ」の画面は何も追加せずスキップして良い
   （スコープはコード側で指定する）
5. 「テストユーザー」の画面で、**自分のGoogleアカウントのメールアドレスを
   追加**する（これをしないと認証時にエラーになる）
6. 保存して完了

## 4. OAuthクライアントIDを作成する

1. 左メニュー「APIとサービス」→「認証情報」
2. 「認証情報を作成」→「OAuthクライアントID」
3. アプリケーションの種類は「**デスクトップアプリ**」を選択
4. 名前は何でも良い（例：`project-arc-cli`）
5. 作成すると、**クライアントID**と**クライアントシークレット**が表示される
   （後で使うのでこの画面を閉じないこと。閉じてしまっても、
   「認証情報」画面から後で再確認できる）

## 5. `.env`に設定を書き込む

`project-arc`フォルダの`.env`ファイルを開き（`.env.example`を
コピーして作っていない場合は先にコピーする）、以下を追記する。

```
GOOGLE_CLIENT_ID=（手順4で取得したクライアントID）
GOOGLE_CLIENT_SECRET=（手順4で取得したクライアントシークレット）
```

## 6. 初回認証について

`.env`の設定後、初めて`pnpm morning`を実行すると：

1. ターミナルに認証用URLが表示され、自動的にブラウザが開く
2. Googleアカウントでログインし、「このアプリは確認されていません」
   という警告が出る場合は「詳細」→「project-arc（安全ではないページ）に
   移動」を選択して進む（自分専用のアプリのため問題ない）
3. カレンダーとタスクへのアクセスを許可する
4. ブラウザに「認証が完了しました」と表示されたらそのタブを閉じてよい
5. ターミナルに戻ると、自動的に処理が続行される

この認証は**初回の1回だけ**必要です。認証結果（リフレッシュトークン）は
暗号化して`data/`配下に保存され、次回以降はブラウザ操作なしで
自動的に使われます（`docs/adr/0004-google-oauth-and-token-encryption.md`
参照）。

## 7. うまくいかない場合

- 「アクセスがブロックされました」→ 手順3の「テストユーザー」に
  自分のメールアドレスが追加されているか確認
- 認証後もエラーが出る → `data/google-refresh-token.enc`と
  `data/.token-key`を削除してから`pnpm morning`をやり直す
  （認証をリセットして最初からやり直せる）
- それでも解決しない場合は、エラーメッセージをそのまま共有してください
