# Vision

> 目的は『記録』ではなく、『Ownerが理想の人生に近づくこと』である」
> が最上位の目的地。以下のCore Missionは、そこへ至るメカニズム
> （記録→気づき→判断）を述べたもの。両者は矛盾せず、同じ山を
> 違う角度から見たもの（詳細は`constitution.md`「条文間の関係」参照）。

## Core Mission

Project ARCは情報を保存することが目的ではない。

**目的は、人間の意思決定を改善することである。**

すべての機能は、

> 「今日、自分は何をするべきか」

をより良く判断するために存在する。ログを記録すること、
企業を調査すること、家計を分析すること——これらはすべて
手段であり、目的ではない。

---

## なぜこの一文が重要か

「人生OS」というコンセプトは、機能を並べただけでは
単なる高機能な記録ツールになってしまう危険がある。

- 睡眠を記録すること自体に価値はない。
  睡眠不足が続いていることに気づき、明日の予定を
  調整する判断につながって初めて価値になる。
- 企業研究を50社分ためること自体に価値はない。
  司法試験合格後のキャリア選択、あるいは投資判断の
  精度を上げる材料になって初めて価値になる。
- 支出を記録すること自体に価値はない。
  来月の家計をどう調整するかの判断に使われて
  初めて価値になる。

Project ARCのすべての機能は、この「記録 → 気づき → 判断」
という流れの中に位置づけられなければならない。
どの機能を追加するか迷ったときは、この一文に立ち返る。

---

## Vision（中長期像）

Project ARCは、以下の状態を目指す。

1. **毎朝**、その日の判断に必要な情報（予定・ニュース・
   学習状況・健康状態）が、探さなくても目の前に揃っている状態。
2. **毎晩**、その日の行動と結果が記録され、次の判断の
   材料として蓄積されていく状態。
3. **数ヶ月〜数年単位**で振り返ったとき、「なぜあの時
   その判断をしたか」を後から検証できる状態
   （記録が資産として機能している状態）。
4. 使う人（あなた）が、システムに使われるのではなく、
   システムを使って**より良く、より速く決断できる**状態。

Project ARCの成功は、機能数でも記録の量でもなく、
「意思決定の質とスピードが上がったかどうか」で測る。
